# Site Gabriel Eufrasio

Pronto para GitHub Pages com `psicologogabrieleufrasio.com.br`.

## Estrutura
- `index.html`
- `privacidade.html`
- `CNAME`
- `robots.txt`
- `sitemap.xml`
- `favicon.svg`
- `.nojekyll`
- `css/style.css`
- `js/script.js`
- `assets/images/og-image.jpg`
- `assets/images/hero.webp` (adicione sua foto)
- `assets/images/sobre.webp` (adicione sua foto)

Mantenha `index.html` na raiz. No GitHub: **Settings → Pages → Deploy from a branch → branch principal → / (root)**.
Depois configure **Custom domain** como `psicologogabrieleufrasio.com.br` e habilite HTTPS quando disponível.
